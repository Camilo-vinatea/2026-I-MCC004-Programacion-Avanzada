Detailed Description

template<typename T>
class Matrix1< T >

Matrix1<T>

Matriz 2D dinámica en heap. Análogo a Array4 para estructuras bidimensionales.

Almacenamiento interno

m_pMat → [ fila0* | fila1* | ... ]
↓ ↓
[e00 e01] [e10 e11] ...

Formato de stream

Entrada/salida: rows cols e00 e01 ... e(R-1)(C-1)
